# SOP 重構版 v1.0｜風格層與品管層

## 一、客戶版語氣（第五步與 7B 適用）

### 語氣三原則

1. 直接講人，不講命理流程。客戶讀完要覺得「這是在講我的生活」，不是「這是在解釋一張盤」。
2. 像老師當面說話，一段接一段；每個判斷後面都要有生活例子。
3. 金標範本：知識庫 B1/B2 的老師原文語氣，以及下面這段——

```
你本身是一個有自己堅持，也有自己原則的人。
你做事情不太會隨便決定，通常會先仔細想一想，確認這件事情怎麼做比較適合。
你也會追求比較有效率的模式，不喜歡事情太混亂、太沒方法。
```

### ❌→✅ 對照表（違反任一條即為「客戶版轉譯待修」）

內部語外洩：
- ❌ 夫妻宮飛化到命宮，觸發貪狼心動需求
- ✅ 感情對你來說要穩，但不能無聊；要現實，但不能沒有感覺

校準語外洩：
- ❌ 這裡不能只解成爸爸溝通不清（校準後應寫成……）
- ✅ 你爸爸其實口條不錯、講話有邏輯，只是你們中間有一種說不上來的距離感

名詞堆疊：
- ❌ 命宮廉貞貪狼左輔，財帛宮紫微破軍，官祿宮武曲化權，所以你有格局、有慾望、有責任
- ✅ 你命宮有廉貞、貪狼。廉貞像你心裡的一把尺，會讓你在意分寸、規矩、合不合理。貪狼像你的生活慾望開關，讓你不是只想穩，也想玩、想體驗、想有感覺。

抽象詞不落地：
- ❌ 你有底氣、有格局、重視位置感
- ✅ 你花錢重品質，要用好的、吃好的，生活不能過得太委屈

標籤句外洩：
- ❌ 心坎句：你不是沒脾氣，你是太常先把脾氣收起來。
- ✅ 你不是沒脾氣。你只是太常先把脾氣收起來，等到界線真的被踩到，才一次覺得委屈。

句型模板化：
- 「你不是＿＿，而是＿＿」同一段最多 1 次；連續 3 個主軸用同一句型開頭即為模板化。

### 客戶版禁用詞（掃描用清單）

這裡不能只解成／不可只寫／校準後／舊語意／飛化到／A宮／B宮／來源宮／結果宮／化象／本宮是否足以解釋／啟用對宮／底色檢查／心坎句：／刺點：／內在小劇場：／本命底色

（命宮、身宮、廉貞、化祿等少量名詞可以出現，但出現後必須立刻翻白話。）

## 二、品管層（取代 Final Guard 與 49 種檔名分級）

品管分兩級。能用程式判的不佔 AI 注意力；AI 只評需要語感的部分。

### 第一級：程式可判（後端腳本／人工快掃）

| 項目 | 判法 |
|---|---|
| 第五步正文存在 | 【正式客戶版開始】與【正式客戶版結束】兩標記皆存在且中間有內容 |
| 字數區間 | 標記之間 2500–4000 字（1500–2499 → 降級主軸摘要） |
| 禁用詞掃描 | 上方清單對正文全文比對，命中即列原句 |
| 7A 完整性 | 48 條、每條十欄位標題齊全 |
| 7B 條數 | 8–12 條 |
| 引用量底線 | 第五步提及宮位 ≥10、對宮組 ≥4、事件細節 ≥6 |
| 句型重複 | 「你不是」出現頻率、連續段落開頭相似度 |

### 第二級：AI 評審（獨立一次呼叫，只評不寫）

只評三件事，各給 1–5 分＋列證據原句：

1. 命理方向：星曜語意是否與知識庫一致；因果是否先宮位後星曜。
2. 生活畫面：抽掉命理名詞後，句子是否仍描述具體的人事場景。
3. 客戶可讀：像不像老師講話；有沒有報告腔、填空腔。

### 判定輸出格式（唯一格式，取代 49 種檔名）

```json
{
  "判定": "通過｜待修｜未完成",
  "原因碼": ["內部語外洩", "字數不足", "第一步生活畫面不足", "..."],
  "證據": ["…原句1…", "…原句2…"],
  "修正方向": ["…", "…"]
}
```

原因碼固定 12 個：資料核對不符／星義偏離知識庫／生活畫面不足／模板填空／同格複製／內部語外洩／字數不足／層次缺漏／引用量不足／感情段單需求／句型模板化／未完成中斷。

### 執行方式

- Custom GPT：每張任務卡做完，先自跑該卡「檢核」；第五步完成後，開新對話貼上正文跑第二級評審（評審 prompt 只放品管層本節＋風格對照表）。
- API 管線：每步一次呼叫 → 程式跑第一級 → 不過自動重跑該步（最多 2 次）→ 全部通過後另一次呼叫跑第二級評審 → 產出判定 JSON。

## 三、金標回歸（取代「出錯就加規則」）

1. 挑 2–3 張老師確認過的命盤當金標。
2. 任何任務卡或知識庫改動後，重跑金標命盤，對照老師版本檢查有沒有退步。
3. 發現新錯誤：優先改知識庫條目或任務卡範例，不新增規則；規則總量不得成長。
