# 20｜D1 本命人格推理總控流程

> 定位：**程式端 D1 多次 OpenAI 呼叫的總控編排規格**。
>
> 本文件不是一份要完整塞進單次 OpenAI 呼叫的巨型 System Prompt。它負責決定子任務、資料流、讀取順序、推理順序、資料邊界與輸出結構；各次模型呼叫只取得該任務必要的命盤資料與知識片段。

---

## 一、D1 的任務

D1 只回答：

> 這個人大概是怎樣的人？

包含：

- 人格與價值觀
- 思考方式
- 做事方式
- 金錢、工作、感情、人際與家庭態度
- 長期空缺與追求
- 容易反覆困擾的課題
- 不同生活領域中的強項、矛盾與行為模式
- 所有命理上成立、現實上合理的可能

D1 不回答：

- 某件事何時發生
- 哪一年結婚、失業、破財或生病
- 某個人物已經發生什麼具體事件
- 大限、流年啟動後的事件結果

上述內容屬 D2。

---

## 二、最高推理原則

### 1. 可能性優先

本命盤先建立全部合理可能，不提前刪減，不追求唯一答案。

### 2. 講義優先

所有星曜、四化、雙星與宮位解釋，先查老師講義與已確認工作區文件；不可混入其他流派。

### 3. 主星與宮位共同決定

```text
宮位＝事情發生的生活場景
主星／雙星＝命主在該場景中的主要態度與處理方式
四化／輔煞星＝增加的作用、空缺、反應與修飾
```

### 4. 先整宮、再跨宮

先完成每個宮位自己的全部分析，再進行對宮、暗合、三方四正與飛化整合。

### 5. 人格與事件分層

本命只能寫傾向、價值觀、長期行為與關係模式。具體事件交給 D2。

## 四、輸入資料最低需求

本命盤輸入至少包含：

- 十二宮宮名與地支
- 每宮十四主星
- 雙主星前後順序
- 生年四化
- 文昌、文曲
- 左輔、右弼、天魁、天鉞
- 擎羊、陀羅、火星、鈴星
- 祿存
- 身宮位置
- 飛化來源宮、指定星曜與四化
- 空宮資訊

若缺少資料：

- 只分析已提供部分。
- 不補造不存在星曜。
- 不自行推算未提供的排盤內容。

## 五、全盤第一輪掃描

### Step 1｜找陀羅

標記陀羅所在宮位及相關結構。

陀羅即使單顆也要解：

- 反覆
- 糾結
- 拖延
- 長期困擾
- 想很久仍可能選錯方向

### Step 2｜找生年化忌

標記化忌所在宮位與化忌星曜。

化忌先問：

```text
哪個宮位領域存在空缺？
是哪顆主星的核心存在空缺？
命主會用什麼方式持續追求與補足？
```

再加入該星曜專屬化忌規則。

### Step 3｜統計煞忌

煞忌包含：

- 擎羊
- 陀羅
- 火星
- 鈴星
- 生年化忌

統計：

- 本宮＋對宮
- 本宮＋暗合宮
- 三方四正
- 飛化相關結構

單顆煞星不直接判負面；兩個以上煞忌提高反覆、失衡與影響強度。

### Step 4｜標記四馬地

寅、巳、申、亥加入變動背景，但不直接斷事件。

## 六、十二宮逐宮分析

每一宮都完整跑一次以下流程。

### Step 1｜確認宮位含義層級

先用本宮直接含義。

需要時再使用：

- 飛化延伸
- 對宮延伸
- D2 事件含義（D1 不直接使用具體事件）

### Step 2｜確認空宮規則

若空宮有：

- 擎羊
- 陀羅
- 火星
- 鈴星
- 文昌
- 文曲

不可借對宮主星。

其他情況可借：

- 對宮十四主星
- 該主星生年四化

祿存不阻止借星。

### Step 3｜解主星或雙星

單主星：使用講義完整核心。

雙主星：

- 前星為主
- 後星為輔
- 優先使用固定雙星專屬核心
- 不可臨時把兩顆單星拼接成新核心
- 同宮與對拱分開

### Step 4｜加入生年四化

四化必須配合主星核心：

- 化祿：因主星核心得到多出來的機會、資源或好處
- 化權：因主星核心掌握主導權、決定權或責任
- 化科：因主星核心得到彰顯、名聲
- 化忌：主星核心與宮位領域存在空缺，持續追求與補足

四化不改變雙星固定核心，而是與核心同時存在。

### Step 5｜加入文昌、文曲與其他輔星

可單獨解，也可修飾主星；所有合理組合皆保留。

### Step 6｜加入四煞星

- 擎羊：知道有衝突仍正面處理
- 火星：情緒來得快，未想清楚先反應
- 鈴星：冷靜計算；煞忌集中時容易計算過度引起反感
- 陀羅：反覆糾結，想久仍可能選錯

多顆煞星：保留每顆獨立反應及所有合理交互作用，不預設固定先後。

### Step 7｜加入貴人星與祿存

- 左輔：一起喊話、口頭支持居多
- 右弼：細膩說話與柔性支持
- 天魁：檯面上有能力的貴人
- 天鉞：檯面下有能力的貴人
- 天梁：經驗、照顧、保護、現實貴人與神明庇佑
- 祿存：幫助主星核心產生更多效果；獨坐時只標記該宮位較有不安全感

### Step 8｜完成本宮候選池

建立：

- 主星核心
- 雙星核心
- 主星＋四化
- 主星＋輔星
- 主星＋煞星
- 輔星＋煞星
- 多顆星曜共同作用

所有合理可能保留，不預設單一路徑。

## 七、宮位整合

各宮自身完成後，依序整合：

```text
本宮定主軸
→ 對宮優先影響
→ 暗合補充背後原因
→ 另外兩個三方宮補充能力、資源、壓力與矛盾
→ 飛化建立宮位間長期行為連接
```

### 對宮

本宮有主星時，對宮不能直接當本宮主星；用來分析：

- 內外差異
- 背後想法
- 兩種特質同時存在
- 相互影響

空宮借星符合條件時，借星代表表裡如一。

### 暗合

依地支六合：

- 子丑
- 寅亥
- 卯戌
- 辰酉
- 巳申
- 午未

暗合宮是背後默默影響本宮的人、事、物與原因；好壞都要看。

### 三方四正

本宮如總裁，其他宮位如部門。

本宮保有主導權；其他宮位提供能力、資源、壓力與修正。

### 飛化

依 `06` 與 `19` 文件執行：

- 先完成出發宮整宮分析
- 再完成落入宮整宮分析
- 被飛化星曜必須原本存在
- 建立所有合理且不同的生活化候選
- 不把本命傾向寫成已發生事件

---

## 八、身宮整合

身宮在命主獨立自主後逐漸明顯。

- 身宮所在宮位：命主獨立後特別在意、需要滿足的領域
- 宮內主星：用什麼方式追求滿足
- 以命宮個性為主，身宮不能取代命宮
- 命身同宮：更重視自己的人生價值、能力與方向，特質更一致，也較固執

---

## 九、跨宮人格統計

十二宮分析完成後，建立三類標記。

### 1. 跨宮穩定特質

同一特質在多個宮位出現，標記為跨領域核心特質。

### 2. 單一領域高強度特質

只出現在某宮，但本宮、對宮、暗合與三方都指向同一方向，標記為該領域特別明顯。

### 3. 跨領域差異

不同宮位出現相反特質，全部保留：

- 分開看：不同生活領域使用不同方法
- 合併看：命宮可能修飾其他宮位，但不一定每次都受影響

D1 內部資料不等於客戶版文章。建議輸出結構：

```yaml
personality_model:
  core_traits: []
  long_term_needs: []
  recurring_struggles: []
  cross_palace_traits: []
  domain_profiles:
    ming: []
    parents: []
    fortune: []

    career: []
    friends: []
    travel: []
    health: []
    wealth: []

    spouse: []
```

每個候選建議包含：

```yaml

  palace: "宮位"

  scope: "人格/價值觀/長期行為"
  event_boundary: "若涉及具體事件，須交由 D2"
```

## 十一、禁止事項

D1 不得：

- 任意拼接不存在的雙星
- 向落入宮新增不存在的飛化星曜
- 把化忌直接等同失敗
- 把單顆煞星一律判負面
- 把所有可能壓成一條自稱最準的答案
- 用 CTA 簡化宮位含義覆蓋 D1 完整含義
- 將本命傾向寫成已發生事件
- 直接診斷疾病、精神疾病或違法事件
- 把工作推導假裝成老師已確認
