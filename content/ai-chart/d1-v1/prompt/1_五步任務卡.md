# SOP 重構版 v1.0｜五步任務卡

每張卡＝一次執行單位。格式、範例、規則都在卡內，卡外不再有其他規則。

## 任務卡 1｜第一步：單宮單星逐分面生活化推導

輸入：命盤原始資料＋知識庫 A（星曜本義）＋知識庫 C（宮位分面）＋知識庫 B1/B2（雙星宮位對應條目）。

產出格式（每宮一段，12 宮全做）：

```
## ＿＿宮｜＿＿地支｜宮干＿＿
宮位分面：＿＿、＿＿、＿＿（以知識庫 C 為準）
主軸星曜：＿＿｜修正星曜：＿＿｜只列觀察：＿＿

### ＿＿星
星曜本義：（抄知識庫 A 的核心，一句話）
- ＿＿分面：（這顆星讓命主在這件事上怎麼想 → 生活中怎麼做、怎麼被看見 → 與同星其他分面的差異）
```

規則（只有這 6 條）：

1. 星曜本義只能抄知識庫 A；雙星宮位先查 B1/B2 有無現成條目，有就以它為基礎展開。
2. 無煞忌先寫中性／正向，之後才依煞忌補壓力面。
3. 每格必須含生活畫面；拿掉分面名稱後仍看得出這格在講什麼，才算合格。
4. 同星跨分面必須有差異，不可換詞複製。
5. 祿存、天馬、雜曜依知識庫 A 的規則處理，不主動展開。
6. 全部 12 宮寫完才算完成，不可挑宮。

合格範例：

```
廉貞｜命宮｜個性
廉貞放在命宮個性，會讓她不是那種什麼都可以、什麼都好的人。
她平常可以配合，也不是不好相處，但心裡其實有一把尺。對方講話有沒有分寸、做事有沒有規矩、關係有沒有踩線，她會先在心裡感覺到。
所以她的個性不是馬上爆，而是先觀察、先忍、先判斷。等到她覺得對方越界太多，態度就會突然變硬。
這一格講的是她平常個性裡的界線感，不是在講價值觀，也不是在講能力。
```

```
火星｜遷移宮｜外界對自己的看法
火星放在遷移宮的「外界對自己的看法」，代表別人看她時，容易覺得她反應快、有熱情，也有一種事情來了就想馬上處理的感覺。
她在外面不太像慢慢吞吞的人。遇到她有興趣的事情，眼神、語氣、動作會很快熱起來，別人會覺得她有衝勁、有熱忱。
但火星也有急、三分鐘熱度的味道，所以外界也可能覺得她投入快，熱度下降也快。
這一格講的是外界怎麼看她，不是在講她自己內心真正怎麼想。
```

不合格寫法（出現即重寫）：

```
因為＿＿星代表＿＿，所以在＿＿宮的「＿＿分面」上，命主會用＿＿去判斷和處理這個分面。
```
原因：程式填空、沒有生活畫面、可以套到任何星任何宮。

檢核（自答是／否，有「否」就修完再交）：星義是否全部出自知識庫｜無煞忌是否先中性正向｜每格是否有生活畫面｜同星分面是否有差異。

## 任務卡 2｜第二步：生年四化生活事件推導

輸入：第一步產出＋知識庫 A 的四化表與四化規則。

產出格式（每顆生年四化一段）：

```
## ＿＿星化＿＿在＿＿宮
星曜本義：（沿用第一步）｜四化本義：（抄知識庫 A）

### 分面：＿＿
這個分面對應的人事物：＿＿。
這顆星原本怎麼處理這件事：＿＿。
化＿＿之後變成什麼生活事件：＿＿。
與同星其他分面的差異：＿＿。
```

規則（只有 5 條）：

1. 星曜本義必須與第一步一致，不可回到別的解釋。
2. 化權要回答「誰想掌握、主控權在哪、有沒有主導權拉扯」，不可寫「變強」。
3. 化忌走四層：有空缺 → 很在意 → 想補起來 → 過度才成壓力；不可直接解成不好、失敗。
4. 每個分面要有事件（誰、在什麼場合、發生什麼），不可只套四化本義。
5. 太陽系四化提醒：太陽不只照顧幫忙，要補「被看見、出面、存在感」；天相化忌不只規則不清，要補「規則有空缺、想把規則找回來」；武曲化權要補「專業、正財、實際成果」。

合格範例：

```
太陽化祿在僕役宮｜同事
太陽在僕役宮，本來就有出面、照亮、被看見、願意推動事情的意思。
化祿後，職場裡不是只有同事緣變多，也不是只有她會幫忙，而是事情卡住時，大家更容易看到她、想到她，也更容易期待她出來提醒、協調或把問題攤開。
生活中像是群組沒人回、流程沒人推、責任沒人講清楚時，她可能會先出來說一句、整理一下，讓事情繼續往前。
這一分面看的是職場裡的出面機會與存在感，不是朋友日常關心，也不是合作約定。
```

不合格寫法：「武曲化權在官祿宮，代表工作掌握權強。化權後此分面會出現掌握、主導、責任。」——只有本義、沒有事件、沒有對象。

檢核：星義是否與第一步一致｜每分面是否有具體事件與對象｜化權化忌是否照特別規則走。

## 任務卡 3｜第三步：本宮＋對宮生活對接

輸入：第一、二步產出。六組對宮全做：命遷、兄僕、夫官、子田、財福、疾父。

產出格式（每組逐分面）：

```
## ＿＿宮＋＿＿宮
本宮星曜：＿＿｜對宮星曜：＿＿

### 本宮分面：＿＿｜對宮分面：＿＿
本宮星曜在此分面的表現：＿＿。
對宮星曜補了什麼：＿＿。
合起來的生活畫面：＿＿。
與同組其他分面的差異：＿＿。
```

規則（只有 4 條）：

1. 對宮要講成生活互動，禁句：「被對宮拉出反應」「這一格看的是＿＿如何被＿＿補充」「兩宮互相影響」。
2. 同組不可多格共用同一段生活畫面；三格以上只換分面名稱即不合格。
3. 星曜語意沿用第一步。
4. 每格要有場景（誰、什麼情境、她怎麼反應）。

合格範例：

```
命宮＋遷移宮｜個性＋在外人際關係
命宮廉貞讓她個性裡有界線，貪狼讓她對人事物有反應，左輔讓她看到事情卡住時容易想補位。
對宮遷移宮火星，代表她在外面遇到人際刺激時，反應會比較快，也比較容易被當下氣氛點燃。
所以生活中像是：朋友臨時丟一個問題、外面有人催進度、現場氣氛突然變急，她不太會完全沒反應。她可能很快想處理，也會很快判斷自己要不要接。
這一格看的是她個性被在外人際刺激時的反應，不是在講外界怎麼評價她。
```

```
疾厄宮＋父母宮（合格方向示範）
爸爸或長輩講到身體、作息、生活方法時，她不一定馬上照做。她會先把這些話放進心裡，再用自己的方法查資料、整理做法。她跟爸爸不是不能溝通，只是中間有一點距離感，所以她需要先聽懂對方的意思，才知道怎麼自然靠近。
```

檢核：是否六組全做｜是否零禁句｜每格是否有獨立生活畫面。

## 任務卡 4｜第四步：宮干飛化完整反推（7A）＋客戶事件轉譯（7B）

輸入：第一～三步產出＋知識庫 A 四化表。
本體：12 來源宮 × 4 條＝48 條，一條都不能省。內容太長分段輸出，不可摘要。

### 7A 每個來源宮先建總表：

```
## 來源宮：＿＿宮｜宮干：＿＿
本來源宮四化：＿＿星化祿到＿＿宮／化權到＿＿宮／化科到＿＿宮／化忌到＿＿宮
A宮來源清單：（列第一步的真實來源格 2–3 條＋第三步補充，含原句摘要）
此來源宮可共用背景：＿＿。
```

### 7A 每條飛化固定十欄：

```
### ＿＿宮＿＿干｜＿＿星化＿＿到＿＿宮
1. 宮位因果（先不看星曜）：A宮代表＿＿；B宮代表＿＿；A宮為什麼能讓 B宮變化：＿＿。
2. 化象動作：本條為化＿＿，基本意思＿＿，所以先定義為＿＿。
3. B宮來源清單：（列第一步／第二步真實來源格，不可寫「B宮基礎狀態為……」）
4. 本宮自洽／對宮補因：本宮是否足以解釋：是／否；若否→卡在哪、啟用哪個對宮、補了什麼、補完是否合理。
5. 本命底色：B宮是否已有生年四化；有→本條只能寫觸發／加重／引動／帶出。
6. 星曜修飾：這顆星讓這件事「透過什麼方式」發生（不可寫「用這顆星的方式處理」）。
7. 生活實際行為：命主實際會做什麼（看得見的真人動作）。
8. B宮結果畫面：行為作用到 B宮人事物後，生活中會看到什麼。
9. 白話收束：這不是單純＿＿，而是＿＿。
10. 生活翻譯三句：觸發：＿＿。命主反應：＿＿。生活結果：＿＿。（三句都能直接講給命主聽；寫不出來＝前面因果沒推通，本條重推）
```

規則（只有 6 條）：

1. 每條第一個問題永遠是「A宮為什麼能造成 B宮變化」，不可先解星曜、不可先拉對宮。
2. 同源宮四條可共用「來源背景」，不可共用「反推行為」。
3. 對象欄必須是生活對象（爸爸、同事、另一半、錢、房子……），不可寫靈魂、潛意識、社會價值觀這類分面名。
4. 禁句：「當＿＿出現狀況、需求或刺激時」「此處會被帶動」「把這個動作放到＿＿上」「＿＿底色上」。
5. 三句翻譯內不可出現 A宮、B宮、飛化、化象等內部語；「命主／她」擇一，不可混用。
6. 只寫檢查結論（是／否）而沒把生活事件寫出來，該條不算完成。

### 7B 客戶事件轉譯稿（48 條完成後才做）：

從 48 條挑 8–12 條主軸飛化，每條寫成：

```
### 事件＿＿：＿＿（白話標題）
白話結論：＿＿。
觸發點：＿＿。
命主反應：＿＿。
生活畫面：＿＿。
影響結果：＿＿。
提醒：＿＿。
```

7B 禁止出現任何內部欄位語（本宮是否足以解釋、啟用對宮、底色檢查、行為對象現象檢查）。

### 4A／4B（7A 完成後產出）

4A 飛化索引：48 條一行一條（來源宮干＋星化象＋到宮＋一句生活結論），不可公式化。
4B 客戶個性細節主軸：把多條指向同一議題的飛化群組成 3–6 個主軸。

檢核：是否 48 條完整｜每條是否十欄齊全且有生活事件｜7B 是否 8–12 條且零內部語｜4A/4B 是否在 7A 之後。

## 任務卡 5｜第五步：主軸排序＋全素材整合＋正式客戶交付稿

輸入：第一～四步全部產出＋風格檔（2_風格與品管.md）。

### 5-1 主軸排序（內部整理）

```
第一主軸：＿＿（來源｜為什麼是主軸｜客戶版要回答什麼）
第二主軸：＿＿（同上）……
簡短帶過的背景：＿＿｜不放入客戶版的細節：＿＿
```

排序依據：命宮身宮優先 → 生年四化宮位優先 → 三方四正與對宮重複指向優先 → 多條飛化重複指向的議題優先 → 與使用者問題相關優先。單一飛化、無其他步驟支持的細節不可升格為主軸。

### 5-2 全素材整合表（內部整理，10 類每類都要填來源與重點）

A 命主本質｜B 外界看她與人際反應｜C 爸爸媽媽長輩與家庭｜D 感情與另一半｜E 工作與生活重心｜F 金錢與安全感｜G 享受品味玩樂｜H 身體壓力作息｜I 內在壓力與精神卡點｜J 最後提醒
（每類註明取自第幾步哪些宮，「要寫給客人的重點」一句話）

### 5-3 正式客戶交付稿

```
【正式客戶版開始】
（正文）
【正式客戶版結束】
```

規則（只有 7 條）：

1. 正文 2500–4000 字；1500–2499 字只能命名為「長版主軸摘要」，不可稱完整交付。
2. 十二層次都要講到（一句話定位、核心個性、做事方式、外界觀感、人際、家庭長輩、感情、工作、金錢、享受、身心壓力、課題建議），不必用小標題硬切。
3. 全篇用「你」稱呼命主，像老師當面講話；一段接一段，不是條列報告。
4. 只能整理前四步已支持的內容，不可新增前面沒有的重大結論。
5. 引用量底線：第一步至少 10 宮的素材、第三步至少 4 組對宮、第四步至少 6 條事件細節——這是「內容涵蓋」要求，由全素材整合表對照，不是要在正文點名宮位；正文名詞仍以風格層為準。
6. 感情段必須同時講「穩定、現實、責任」與「心動、吸引、生活有味道」兩種需求（例：你要穩，但不能無聊；你要現實，但不能沒有感覺）。
7. 語氣與禁句以 2_風格與品管.md 為準；命理名詞可少量出現，出現後立刻翻白話。

檢核：字數區間｜十二層次｜引用量底線｜感情段雙需求｜開始結束標記存在。
