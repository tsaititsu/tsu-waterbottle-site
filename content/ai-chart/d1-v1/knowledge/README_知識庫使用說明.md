## 這套知識庫取代了什麼

取代 SOP 正式基準版 v1.14 裡的「星曜講義校準表」機制。原本要求 AI 在解盤前自己生成校準表（但講義不在檔案裡，AI 只能靠訓練資料的雜訊知識），現在直接查表：

- 第一步查 A（星曜本義）＋ C（宮位分面）
- 雙星宮位直接查 B1/B2 對應條目，取用該宮位的生活描述
- 第二步四化查 A 的四化表與規則
- 客戶版語氣以 B1/B2 原文為金標範本（這些就是老師自己的說話方式）

## 給 Custom GPT / API 的掛載方式

- Custom GPT：四個檔案全部上傳到 Knowledge；Instructions 裡只需一句「星曜與宮位解釋一律以知識庫檔案為準，不足標『待老師補充』」
- API 管線：每步只注入該步需要的段落（第一步注入 A＋C；雙星命盤另注入 B 的對應條目），控制每次呼叫的上下文量

## 維護規則

1. 老師新增或修改講義 → 只改這裡，不改 SOP 流程檔
2. 每個條目保留講義原文語氣，僅去除社群開場白；修改時同樣保持老師原文
3. 版本升級整檔複製為 知識庫_v1.1，不要在流程檔裡累積「校準規則」
