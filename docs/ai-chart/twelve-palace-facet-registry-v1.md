# D1 本命人格十二宮分面 Registry v1

## 文件狀態

這是本命人格架構的宮位責任草案，不是正式程式 Schema，也尚未授權接入付費報告。

本文件把老師講義、舊 SOP、既有小卡及本輪最新決策整理成單一宮位分面來源。後續卡片、Contract、Prompt 與測試只能引用這份 Registry 已允許的分面，不得再直接從舊表任選宮位含義。

## 權威順序

1. 老師在目前架構討論中的最新確認。
2. 老師講義與課程資料的直接說明。
3. 經老師確認的核心卡與推理卡。
4. 已確認的 D1 規格。
5. 工作版、舊 SOP 與整理範例。

檔名中的「正式」或較大的版本號不能覆蓋老師後來的明確修正。

## Registry 使用規則

### 分面不是必填作文格

- Registry 定義「這個宮位可以談什麼」，不代表每張命盤都要把每個分面寫滿。
- 只有星曜、四化、輔煞或正式跨宮關係能形成可追溯主張時，才建立內容格。
- 沒有足夠命理依據的分面保持空白，不要求模型硬生內容。
- 同一分面可以保留多個不同機制；同一機制只需挑一至兩個客戶容易理解的代表例子。

### 固定推演鏈

每項宮位主張必須符合：

```text
命盤事實
→ 星曜或規則的固定核心
→ Registry 允許的宮位分面
→ 目的／感受／價值
→ 選擇或行為
→ 可能生活表現
```

生活例子不能反過來改寫星曜核心，也不能跨到 Registry 未授權的宮位分面。

### 本命與事件分工

- D1 只描述長期人格、價值、偏好、互動方式及可能表現。
- 實際收入、婚姻、疾病、房產、事件結果與發生時間留給大限、流年及事件推演。
- 客戶文章使用「可能、容易、如果、例如」等邊界，不冒充已知道客人的真實經歷。

### 宮位主體

- 命宮、財帛、疾厄、遷移、官祿、田宅、福德以命主為主要主體。
- 父母與兄弟可以先描述早於命主存在的人物／家庭關係，再另建命主感受與互動主張。
- 夫妻、子女及交友先描述命主的態度與行為；另一方只能作條件式「關係對象可能」。
- 雙主星在人際分析中同時保留完整雙星與前星他人／後星命主的互動角色，不可只留其中一種。

### 飛化使用方式

飛化推演可以把宮位當成來源或受影響領域，但仍須從本 Registry 的合法人物、經驗及生活分面建立因果。飛化不會增加新的宮位含義，也不能把 D2 事件提前寫進 D1。

## 1｜命宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `life.core_personality` | 核心個性 | 命主較穩定的性格基調與自然反應。 |
| `life.values_direction` | 價值與人生方向 | 命主重視什麼、希望自己成為怎樣的人及做決定的方向。 |
| `life.thinking_behavior` | 思考與行為模式 | 命主通常如何思考、選擇及行動。 |
| `life.capability_tendency` | 能力傾向 | 可能擅長或較容易發展的能力，只能寫傾向，不能寫成成就。 |
| `life.strengths_blindspots` | 優點與盲點 | 同一人格核心在順利及失衡時的不同表現。 |
| `life.appearance_optional` | 外在樣貌補充 | 只有講義依據充分時低比重提及，不作報告重點。 |

### 邊界

- 命宮提供整體人生方向，但其他宮位平常各自運作。
- 不把命宮主星自動複製到其他十一宮。
- 只有煞忌、三方四正、暗合、飛化或其他正式關係成立時，才建立跨宮影響。

## 2｜兄弟宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `siblings.mother` | 媽媽 | 先描述媽媽的可能特質，再描述其對命主感受與互動方式的影響。 |
| `siblings.same_gender_siblings` | 同性別兄弟姊妹 | 命主對同性別手足的態度、互動方式及可能感受到的對方特質。 |
| `siblings.new_friends` | 新認識的朋友 | 命主剛認識朋友時的態度、判斷與相處方式。 |
| `siblings.relationship_impact` | 既存關係影響 | 既存人物特質如何形成命主的主觀感受、距離與應對。 |

### 邊界

- 媽媽可作既存人物現象，不等於把媽媽的星曜直接算成命主個性。
- 一般同事與團隊合作歸交友宮。
- 實際家庭事件、手足事件與時間不屬 D1。

## 3｜夫妻宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `relationship.attitude` | 感情態度 | 命主如何看待感情、親密關係與長期相處。 |
| `relationship.needs_expectations` | 感情需求與期待 | 命主在關係中重視、期待及在意什麼。 |
| `relationship.preferred_partner` | 容易欣賞的對象 | 命主容易被什麼特質吸引，只能寫成可能性。 |
| `relationship.partner_possibility` | 伴侶特質可能 | 命主在關係中可能遇到或感受到的對象樣貌，不冒充現任或未來伴侶事實。 |
| `relationship.interaction` | 相處與對待方式 | 命主如何建立、維持、表達及調整感情關係。 |

### 邊界

- 預設使用中性關係語言，不假設婚姻狀態與對象性別。
- 目前不分析性生活與親密需求細節。
- 工作在外與合作狀況不放入一般本命報告。
- 結婚、分手、外遇及年份屬 D2。

## 4｜子女宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `care.children` | 小孩教養 | 命主如何照顧、教導及安排小孩；不預設命主已有小孩。 |
| `care.pets` | 寵物照顧 | 命主如何選擇、照顧及與寵物互動；不預設命主已有寵物。 |
| `pleasure.eating` | 吃的選擇與行動 | 命主實際怎麼選擇、安排及享用飲食。 |
| `pleasure.play` | 玩樂方式 | 命主實際如何選擇及安排娛樂活動。 |
| `pleasure.travel` | 旅遊方式 | 命主實際如何選擇、安排及進行旅遊休閒。 |
| `possessions.owned_items` | 所有物 | 東西成為命主的物品後，命主希望它呈現的形象、價值及使用方式。 |

### 共用底層

- 小孩與寵物共用「照顧需要自己負責的生命」機制，但客戶例子分開。
- 吃、玩樂與旅遊在子女宮回答「實際怎麼選、怎麼安排及怎麼做」。
- 所有物回答「已經屬於自己的東西，希望它成為什麼樣子」，不重複財帛宮的購買與花錢。

### 邊界

- 排除性生活與親密需求。
- 排除「家門外」的固定分面。
- 排除財庫；財庫與存錢方式歸田宅宮。
- 不把教養方式延伸成主管管理員工。

## 5｜財帛宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `money.view` | 金錢觀 | 命主怎麼看錢、價值、投入與回報。 |
| `money.earning` | 賺錢方式 | 命主希望靠什麼能力、方法或工作方式取得收入。 |
| `money.spending` | 花錢方式 | 命主願意為什麼花錢、購買時怎麼選。 |
| `money.management` | 理財方式 | 命主如何研究、分配及管理金錢。 |
| `money.practical_use` | 實際用錢方式 | 命主在生活中如何使用金錢與安排支出。 |

### 邊界

- 不處理存錢、財庫與資產保留方式；這些歸田宅宮。
- 不斷言實際收入、財富、投資成敗或破財事件。
- 「賺錢方式」是人格傾向，不是保證命主靠該方式賺到錢。

## 6｜疾厄宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `body.care_direction` | 身體保養方向 | 講義支持的相對弱項與平時可留意的保養方向。 |
| `body.use_consumption` | 身體使用方式 | 命主如何使用、消耗、休息及照顧身體。 |
| `body.inherited_tendency` | 遺傳傾向提醒 | 父母宮與身體規則支持的遺傳相關傾向，集中在本宮說明。 |
| `body.stress_response` | 壓力與身體反應 | 長期情緒、壓力與身體使用之間的可能模式。 |
| `body.appearance_optional` | 外貌與體態補充 | 只有正式來源充分時低比重提及。 |

### 邊界

- 只能提供保養提醒，不能作醫療診斷。
- 不預測疾病、手術、受傷或交通事故。
- 不在父母宮重複展開遺傳與身體弱項。

## 7｜遷移宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `outside.presentation` | 在外呈現 | 命主離開熟悉環境後如何表現及呈現自己。 |
| `outside.relationships` | 在外人際 | 命主在外面如何與人互動及相處。 |

### 邊界

- 不把別人眼中的形象當成命主完整人格或客觀事實。

### 核准分面

|---|---|---|
| `social.opposite_gender_siblings` | 異性別兄弟姊妹 | 命主對異性別手足的態度、互動及可能感受到的對方特質。 |
| `social.friends` | 朋友 | 命主如何選擇朋友、相處及看待友誼。 |

- 主管不是平輩或一般同事，不因年齡相近而改變。
- 不建立「工作中的主管溝通」固定分面。
- 朋友、同事及團隊成員的特質只作條件式關係對象可能。

| `work.direction` | 職涯方向 | 命主偏好的工作方向、職涯發展及工作目標。 |

- 不建立主管溝通固定分面。
- 升遷、創業、失業與實際職務變動屬 D2。

|---|---|---|

| `home.nearby_environment` | 住家附近環境 | 講義明確支持的附近環境特徵；不等同風水吉凶。 |
| `home.family_interaction` | 家人相處 | 家庭成員的相處、空間共享及家庭運作方式。 |

### 邊界

- 目前不處理風水。
- 目前不分析家世背景。
- 本命只描述存錢、累積及保留資產的方式與傾向。
- 不斷言實際財產金額、是否有房、是否有錢或最後一定守得住財富。
- 房產買賣、搬家及資產成敗屬 D2。

### 邊界

- 不把花錢、賺錢及來財方式當作本宮預設人格分面；相關行為回財帛宮。
- 不預測實際福氣、財富、老年事件或命運結果。

## 12｜父母宮

### 核准分面

| 分面 ID | 分面 | D1 責任 |
|---|---|---|
| `authority.father_person` | 父親／主要父系長輩 | 可先描述父親或相應長輩的可能特質。 |
| `authority.relationship_impact` | 父親關係影響 | 對方特質如何形成命主的主觀感受、距離及相處方式。 |
| `authority.elder_attitude` | 對長輩的態度 | 命主如何看待、回應及與長輩相處，可涵蓋沒有父親的情境。 |
| `authority.upbringing` | 教育與成長經驗 | 父親、重要長輩或家庭教育如何影響命主的價值與處理方式。 |
| `authority.hierarchy` | 對主管階層與上位者的態度 | 命主面對權力、階層及具體上位者時的態度。 |
| `authority.institution` | 對政府與制度的態度 | 命主如何面對政府機關、規章及抽象制度。 |

### 邊界

- 父親／長輩人物狀態與命主自己的態度必須分成不同主體。
- 沒有父親時，不硬套父親事件；可使用重要長輩、教育方式及成長經驗。
- 抽象機關不是前星人物；只有具體官員或承辦人才可作互動對象。
- 主管階層屬權威態度，不等於建立「工作中的主管溝通」固定分面。
- 遺傳與身體弱項詳細說明歸疾厄宮。

## 舊來源差異處理

| 舊來源內容 | v1 處理 |
|---|---|
| 命宮平時影響其他十一宮 | 改為提供整體方向；只有正式跨宮關係成立時才影響其他宮。 |
| 父母宮詳細說身體遺傳與身體使用 | 遺傳相關訊號集中到疾厄宮作保養提醒。 |
| 福德宮包含來財、花錢與老年生活 | 金錢行為歸財帛，實際老年事件延後；福德保留內在價值與精神層。 |
| 田宅宮包含風水 | 目前排除風水，保留居家及附近環境。 |
| 官祿宮包含同事、感情對象及感情內心 | 同事歸交友、感情歸夫妻；官祿只處理工作。 |
| 僕役宮使用泛稱平輩／異性別同輩 | 使用交友宮；保留異性別兄弟姊妹、朋友、一般同事及團隊互動。 |
| 子女宮包含性生活、家門外及財庫 | 三項全部排除；財庫歸田宅。 |
| 夫妻宮包含工作在外 | 不進一般本命人格報告，保留未來特定情境再評估。 |
| 財帛宮與田宅宮都談財庫 | 財帛只處理看錢、賺錢、花錢、理財及用錢；田宅處理存錢與資產保留。 |
