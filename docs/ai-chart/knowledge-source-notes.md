## 素材與模型的界線

老師素材提供：

- 星曜底層核心。
- 宮位含義與分面。
- 四化、煞忌、身宮與飛化規則。
- 雙主星與主體規則。
- 禁止越界的命理限制。

模型可以：

- 把底層核心延伸成多種合理的生活表現。
- 依客人主要生活地區調整例子。
- 用自然語言直接說明人格與關係。

模型不可以：

- 從網路常識補造紫微規則。
- 把生活例子倒寫成固定命理規則。
- 把可能性寫成客人真實經歷。
- 用模型輸出改寫老師素材。

## 主星核心與宮位內容的分層

- 十四主星核心卡只保留不隨宮位改變的內容：定位、化氣、底層核心、正常與失衡狀態、煞忌使用條件、成立條件及禁止誤解。
- 身體對應、住家對應及十二宮固定落點必須拆成其他規則卡，不能直接視為主星本身在所有情境都成立。
- 買名牌、品種貓等生活例子只是在特定宮位分面下的推演，不是主星核心。
- 老師明確確認的固定宮位結果可以整理成宮位落點卡；模型自行延伸的例子不能回寫成固定素材。

## 六輔星的整合方式

- 主星先決定宮位主要方向，每一顆適用輔星再各自產生補充主張，驗證後才整合。
- 輔星不能取代主星，也不能因文章整併而被漏掉。
- 輔星不只描述外界給命主的幫助，也可以描述命主先展現的行為，以及這種行為可能引起的關係回應。
- 老師最新指定地空、地劫必須保留在 P1 結構輸入；舊素材原本標示「指定才展開」，因此目前先作可追溯觀察，不在固定語義卡尚未完成時自行推論。
- 地空、地劫不加入空宮借星的六個阻擋星，也暫不加入煞忌集中度計分。
- 老師補充地空、地劫較常在大限盤與流年盤使用；本命盤現階段仍只保存可追溯落點。
- 老師研究筆記〈技術篇 19〉原始記錄空劫有同宮、對宮、夾、拱四種：同宮與對宮同一等級，夾與三合拱的作用減半。
- 老師本輪最新決定正式架構只保留同宮與對宮的完整作用，不採用夾與三合拱的半力規則；後續不能只因舊講義存在就自行恢復。
- 空劫的固定核心不是一律帶來壞事，而是使原本的事件結果減弱、取消或無法留下。講義例子包括財福線原本可能有投資成果但最後被空掉、疾厄宮原本可能開大刀而變成不用開或只開小刀，以及夫妻宮原本可能離婚但最後離不成。必須先有原始事件判斷，再判斷空劫如何影響結果。
- 其他未建模小星即使同宮同名，只要來源索引與 placement ID 不同就保留底層紀錄；名稱重複不能阻擋 N0，但這些小星目前仍不進入 P1。
- D1 本命盤優先分析命主自己的特質與主動行為；他人回應只在因果成立時作為第二層補充，不是每項主張的必填內容。
- 老師補充左輔的可能機制：命主喜歡幫助別人、做事夠義氣，因此別人也可能更願意回頭幫助命主。
- 不能把這條因果簡化成「有左輔就一定有貴人」。
- 老師確認左輔的主動核心是願意站在對方這邊、表態支持、講義氣及主動幫忙；它不只是口頭聲援，但也不能單憑左輔斷定一定出錢、提供資源或實際代辦。
- 是否出錢出力要再看主星、宮位與其他星曜；別人回頭幫助命主只是一種第二層可能。
- 老師確認右弼偏向以細膩說話、安慰、提醒、圓場與協調幫助別人，與左輔的站隊、表態及講義氣分開。
- 右弼也可能因命主平常照顧別人情緒而形成回頭幫助；遇煞忌時則可能替錯誤事情圓場或幫錯方向。
- 老師確認天魁是檯面上、身分明確且具有能力、專業或資源的正式實質幫助；命主可能遇到這類貴人，也可能自己公開、正式地成為別人的貴人。
- 天魁不能和左右的表態、安慰、圓場或人情支持混用，兩個方向也要依宮位主體分開。
- 老師確認天鉞是檯面下、具有實際能力、專業或資源的幕後助力；命主可能被私下提醒、牽線、安排或協助，也可能自己在幕後如此幫助別人。
- 天鉞與天魁都有實質效果，差別在公開正式出面或幕後運作；天鉞不能與右弼的安慰圓場混用。
- 老師確認文昌主要描述命主自己的理性、邏輯、條理、規則、文字說明、資料整理及制度內學習方式，可落成問清楚、查資料、列清單或按規則處理。
- 文昌不強制產生他人回應；只有宮位與因果適合時，才可補充別人可能覺得命主說得清楚、有條理或值得信任。
- 老師確認文曲主要描述命主的感受、情緒、美感、表達、創作、表演及氣氛感知；狀態不好時，可能因感受與情緒太多而難以說清楚真正想法。
- 文曲同樣不強制產生他人回應；昌曲固定以「文昌偏理性、文曲偏感性」區分，不能合併成模糊的才華標籤。
- 老師進一步確認：父母宮與兄弟宮在本命盤可先當作早於命主存在的家庭人物／關係現象觀察，因此輔星可以描述父親、母親或該宮人物本身，也可以描述命主在關係中的主動行為。
- 兩種解釋都是可能，但必須拆成不同主體的主張；不能把「爸爸幫人」與「命主幫爸爸」混寫成同一件事。
- 這項例外目前只確認父母宮與兄弟宮，不自動套用到夫妻、子女或交友宮。
- 老師確認夫妻宮、子女宮與交友宮以命主自己的態度與行為為第一層；伴侶、孩子／寵物、朋友／同事等另一方，只能保存成命主可能期待、遇到或感受到的對象特質。
- 這些「關係對象可能」必須使用條件語氣，不可寫成對方已存在或特質已被證實。
- 老師確認父母宮與兄弟宮的單主星要先描述父親、母親等既存人物，再由該人物特質推導命主的主觀感受與相處方式。
- 例如單星紫微在父母宮，爸爸可能愛面子、重尊重；命主可能因而覺得相處需要講禮數、顧及面子或帶有距離。後者是關係影響，不代表命主自己也有紫微。
- 老師確認父母宮雙主星必須分三種用途：爸爸本身是完整雙星狀態；拆雙方對待時前星代表爸爸、後星代表命主；命主面對長輩、主管階層或政府機關時，仍以完整雙星組合解讀。
- 「前星他人／後星命主」只用於雙方互動角色，不能把爸爸整體縮成前星，也不能把命主對權威的整體態度縮成後星。
- 老師確認雙星前後角色切分適用於命主與具體對象的相處，不只父母宮或真人關係：完整雙星描述命主面對該關係的整體態度；前星另可代表對方，後星代表命主。
- 例如兄弟宮雙星：媽媽本身用完整雙星；命主面對同性別兄弟姊妹或新朋友也用完整雙星；拆雙方互動時則以前星看對方、後星看命主。
- 寵物相處也能拆前後星：前星可表示寵物的互動側，後星表示命主；完整雙星仍描述命主養寵物與相處的整體方式。
- 政府機關、制度與抽象權威不當成前星人物；命主面對它們時使用完整雙星。只有分析具體官員或承辦人互動時，才可用前星對方、後星命主。

## 紫微星的示例

紫微的底層核心應從正式講義或卡片取得，例如尊重、面子、主導與格局感。模型可依不同宮位延伸：

- 在命宮：可能重視自己的位置、形象與他人尊重。
- 在父母宮：可能感受到父親或長輩較重視面子，彼此互動可能帶有距離或禮數。
- 在財帛宮：可能較願意為品質、品牌、體面或能代表身分的東西花錢。
- 在官祿宮：可能嚮往有知名度的公司、職位或在工作中建立能見度。

這些都是供客人比對的合理表現，不是「有紫微就一定買名牌」的固定規則。

## 夫妻宮目前決策

正式分面素材列有感情態度、喜歡的對象、另一半、感情相處與工作在外狀況；較新的 SOP 另註明，本命盤先以感情與另一半為主，工作在外只是輔助。

老師在本次討論確認：

- 一般本命人格報告的夫妻宮全部以感情為主。
- 工作在外或合作狀況不放入預設報告。
- 該工作面向先保留給未來明確工作詢問或其他適用情境。
- 單主星同時轉譯命主的感情態度與可能的伴侶類型，但必須分清主體。
- 伴侶層是命主容易欣賞、期待、吸引或感受到的可能性，不能斷言實際伴侶一定如此。
- 雙主星前星偏伴侶／他人、後星偏命主，另保留兩星形成的相處互動。
- 預設不假設客人已婚、有現任伴侶或喜歡特定性別；自願提供的關係狀態只用來調整稱呼。
- 本命層不預測結婚、交往、分手等事件與時間；這些留待大限及流年。
- 目前本命人格報告不分析性生活與親密需求。

## 子女宮目前決策

- 小孩與寵物共用「教養與照顧方式」底層分面，客戶文章再分開舉例。
- 不預設客人一定有小孩或寵物，也不把這個分面延伸成主管管理員工。
- 老師補充：紫微在子女宮，養貓時較容易挑品種貓。
- 正確機制不是泛稱「重視品質」，而是紫微愛面子，寵物會成為自身形象的投射，因此傾向選看起來高貴、有身價、能讓命主有面子的品種貓。
- 不能把品種貓本身當成紫微固定核心；它是「愛面子」落到子女宮寵物分面的生活推演。

## 老師補充規則：紫微在福德宮

- 紫微可想成皇帝。皇帝通常生長於較好的環境，不是從底層艱苦生活磨練出來的角色。
- 高難度運動、長期吃苦或主要依靠強大意志力支撐的活動，不是紫微自然傾向選擇的生活方式。
- 紫微落在福德宮時，這個核心會進入命主的內在驅動與精神狀態，因此可以解讀為意志力或長期硬撐能力相對較弱。
- 固定推演鏈是「皇帝式的靈魂與成長環境 → 不以長期吃苦、硬撐為自然選擇 → 放在福德宮時，意志力與內在續航相對較弱」。
- 這是相對傾向，不等於懶惰、沒有能力、任何事情都做不到，也不能泛化成紫微落入所有宮位都意志力弱。

## 子女宮所有物與財帛宮的分工

- 即使生活例子相關，兩宮仍必須保留不同因果，不能用相同段落重複交付。

## 四煞的主體規則

- 老師確認擎羊、陀羅、火星與鈴星不是沒有主體的負面修飾。
- 每條四煞主張都要標明在描述關係人物、命主自身，還是雙方關係受到的影響。
- 例如擎羊在父母宮，可分成爸爸遇衝突時較直接強硬、命主感覺彼此容易硬碰硬，以及命主面對長輩或具體權威人物時較直接不退讓。
- 三種都是合理可能，但不強迫全部寫滿，也不能把不同主體混成一句。

## 四化隨星隨主體

- 老師確認生年四化必須跟著被四化的星曜及當下分析主體，不能把四化獨立抽出後任意換到命主或另一個人身上。
- 老師確認化祿除了機會、資源與好處，也包含好感、緣分增加及較容易靠近；具體如何增加仍要回到被化祿星曜的核心、宮位與主體。
- 老師確認化祿作用在父母宮的父親／長輩關係時，通常可解成與爸爸或長輩較有緣，也可能得到爸爸或長輩帶來的好處。
- 父親／長輩人物狀態、命主感受到的緣分，以及實際可能得到的好處必須分開保存；「較有緣」不能寫成父親一定照顧命主。
- 舊 SOP 已有直接依據：v0.8 寫明「父母宮化祿：爸爸、長輩緣分增加，容易有爸爸或長輩帶來的好處」；正式基準版 v1.2 也把化祿定義為增加、好感、緣分、資源與容易靠近。
- 目前 D1 工作卡 `07_四化正式規格_工作版.md` 的化祿共通公式只列機會、資源與好處，尚未完整帶入好感、緣分與容易靠近；同一工作卡也以命主為唯一預設主體，後續實作需依老師最新確認改成隨星隨主體。
- 老師確認化科的共通作用是讓被化科星曜的核心被看見、被注意，牽動名聲、形象、曝光、修飾或被說明清楚；具體內容仍須隨星隨主體。
- 紫微化科在父母宮時，爸爸可能因身分、體面、領導樣貌或代表性被看見；也可能因紫微本來重尊重與面子、化科又凸顯名聲與外界眼光，而顯得很愛面子。
- 命主可能覺得爸爸重名聲、重體面或在意別人的看法；這是命主對爸爸的關係感受，不代表命主也有紫微化科。
- 「很愛面子」是紫微核心與化科共同形成的組合推論，不得泛化成所有化科都愛面子。
- 老師確認化忌代表被化忌星曜核心上的空缺、不滿足、放不下或壓力集中，因此主體可能持續追求、反覆在意，嚴重時形成執著、卡住或困擾。
- 化忌仍須隨星隨主體；關係人物的缺口與命主受到的關係影響要分開，不能把父親的缺口直接寫成命主的執著。
- 老師確認底層規則建立完整後，模型應自行組合星曜核心、四化作用、宮位分面與主體，推演自然表達及生活可能，不必人工枚舉所有組合。
- 模型只負責組合與語意延伸；固定卡與程式仍須限制命理來源、驗證 Actor 與來源追蹤，不能讓模型把自己生成的說法升格成底層規則。
- 紫微化權在父母宮時，爸爸是紫微化權的狀態：更重面子、要求尊重、控制欲可能較強，也可能因能掌握權力與別人的尊重而顯得較有能力。
- 命主可能因此覺得爸爸控制欲強、要求尊重或能力不差；這是爸爸特質形成的關係感受，不代表命主也有紫微化權。
- 老師確認化權的共通作用是加強對被化權星曜核心的掌握、執行、控制或承擔能力；具體能力內容由星曜決定。
- 紫微化權偏掌握權威、主導與尊重，天機化權則偏掌握思考、方法、規畫與分析；不能把所有化權都寫成同一種領導能力。

## 祿存與提問前核對

- 老師提醒：每次提出下一個問題前，應先查看講義、推理小卡、核心卡、舊 SOP 與本輪已確認決策；小卡已有的內容不應再要求老師重複回答。
- `14_D1_輔星煞星貴人星祿存.md` 已明寫祿存「與化祿相似，是存在的助力」。
- 同一張卡明確規定：有主星時，祿存幫助主星核心產生更多效果；財帛宮可理解為幫助主星產生更多賺錢機會；獨坐時才標記該宮位較有不安全感。
- 核心卡 `A_十四主星與輔煞四化.md` 補充祿存的資源保留、安全感、不敢亂投入、保守與好處累積，但也強調它是輔助主星，不能取代主星。
- 因此祿存的主軸應先是類似化祿的增益助力；資源保存與安全感是補充修正，不能把祿存只解成保守或不安全感。
- 祿存本身不是獨立人物角色；有主星時沿用該主星正在描述的 Actor，獨坐時則依宮位當下主體說明安全感，不另創造 Actor。

## 遷移宮分面

- 命主在外面如何與人相處及呈現自己。
- 外界的人如何看待命主。
- 命主內心真正的想法。
- 三個分面必須分開保存，避免把外在形象、他人觀感與內在想法混成單一人格結論。

## 兄弟宮與交友宮的人際分工

- 兄弟宮保留媽媽、同性別兄弟姊妹與新認識的朋友。
- 交友宮保留異性別兄弟姊妹、朋友、一般同事，以及團隊裡與人相處的過程、對待方式與價值觀。
- 不建立「異性別同輩」這個分面。
- 主管就是主管，不因年齡較小或與命主同齡而變成平輩或一般同事。
- 目前不建立「工作中的主管溝通」固定分面。
