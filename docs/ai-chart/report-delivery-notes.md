# AI 命盤報告交付備註

這些決策影響網站工作流程與客戶等待體驗，不屬於命理推演規則。

## 交付時間

- 使用者希望正常情況約三分鐘內可領取報告，但目前先不把三分鐘定為正式承諾。
- 應先用完整、脫敏的模型流程量測實際時間，再回來決定合理目標。
- 不得為了追求三分鐘而跳過分析、驗證或飛化階段。
- 真正的逾時與併發參數要等流程固定後量測，不先拍腦袋設定。

## 等待體驗

- 畫面應明確告訴客人一般約三分鐘。
- 客人不想停在頁面，可以離開並等待通知。
- 報告工作必須可續跑，不能綁在瀏覽器連線上。
- 請求送出後結果不確定時，只顯示報告稍有延遲，不向客人暴露 OpenAI 或技術錯誤。
- 不提供客戶自行重送按鈕；原付款與領取資格保持有效，不要求重新付款。
- 內部完成安全處理後，再通知客戶領取。

## 保存與重跑

- 每個宮位的結構化主張要分開保存。
- 飛化、全盤關係、每宮客戶文章與全盤導讀要分階段保存。
- 某宮分析或寫作失敗，只重跑該宮或問題主張。
- 已通過內容不可因單點失敗被丟棄。
- 是否能交付，要依失敗是否實質破壞完整報告決定。

## 客戶文章生成順序

1. 十二宮分析與驗證完成。
2. 飛化與全盤關係完成。
3. 十二宮文章分宮、受控平行生成。
4. 十二宮文章都完成。
5. 最後生成全盤導讀。
