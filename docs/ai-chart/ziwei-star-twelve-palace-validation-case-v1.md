# 紫微星十二宮分面推導驗證案例 v1

## 文件目的

這是一份 D1 本命人格架構驗證案例，不是客戶報告、Prompt、正式 Schema 或模型輸出範例。

本案例用同一顆紫微星逐一進入十二宮，檢查：

1. 固定星曜核心能否自然轉入該宮合法分面。
2. 生活化表現是否仍可追溯到底層核心。
3. 舊 A2 內容經最新 Registry 校正後，是否仍能保留有用推導。
4. 是否會跨宮、硬填分面、偷渡事件或把例子寫成客戶事實。

## 測試邊界

本案例固定為：

- 單星紫微。
- 無煞忌。
- 不加入對宮、三方四正、暗合、飛化、輔星、煞星、身宮、大限及流年。
- 不判斷事件是否發生。
- 不要求每個宮位的每個分面都有內容。

因此，本案例只能驗證「星曜核心 × 宮位分面」這一層。正式本命盤仍須經其他推演引擎逐層補充，不得把本案例直接當完整命盤。

## 固定來源

### 紫微星固定核心

- 帝星、化氣為尊。
- 重視尊重、名聲、面子、形象、品質、被看見及被認可。
- 有領導、整合資源及帶領團隊的傾向。
- 需要團隊、資源及左右手，不能把紫微寫成單靠自己必然成功。
- 無煞忌時先使用正常狀態。
- 高傲、自負、只剩排場等失衡表現，必須有煞忌或其他足夠依據才可提高權重。

### 來源層級

| 代碼 | 類型 | 用途 |
|---|---|---|
| `F` | 固定核心 | 十四主星核心字典已確認的紫微底層語意。 |
| `L` | 講義特殊對應 | 講義直接指定的身體、田宅或其他特殊象意。 |
| `T` | 老師本輪確認 | 老師在目前架構討論中明確補充的案例或邊界。 |
| `D` | 可推導表現 | 由固定核心、合法分面及因果鏈自然推導的生活可能。 |

`D` 不是新的固定命理規則。正式系統必須保存其上游核心及分面，模型也只能在相同邏輯範圍內產生其他例子。

## 推導驗證

### 1｜命宮

**選用分面**

- `life.core_personality`
- `life.values_direction`
- `life.thinking_behavior`
- `life.capability_tendency`
- `life.strengths_blindspots`

**推導**

```text
紫微重視尊重、品質與被看見（F）
→ 命宮的個性、價值與行為（Registry）
→ 希望做事有水準、意見受到重視
→ 狀態合適時願意整合資源、帶人完成事情（D）
```

**可用表現**

- 會在意別人有沒有尊重自己的意見，也希望努力被看見。
- 做事情不喜歡太隨便，通常希望成果有品質、有樣子。
- 有帶領或整合的傾向，但能否真正做到仍要看能力、資源與團隊。

**禁止跨越**

- 不直接寫成一定是主管、成功人士或有領導成就。
- 無煞忌時不把高傲、愛擺排場當主要結論。
- 不把命宮內容自動複製到其他十一宮。

### 2｜兄弟宮

**選用分面**

- `siblings.mother`
- `siblings.same_gender_siblings`
- `siblings.new_friends`
- `siblings.relationship_impact`

**推導**

```text
紫微重視面子、尊重與意見份量（F）
→ 兄弟宮的既存人物及初識關係（Registry）
→ 媽媽或同性手足可能重視家庭形象及自己的話語分量
→ 命主容易感受到相處中是否有互相尊重（D）
```

**可用表現**

- 媽媽或同性手足可能在意家人有沒有尊重他們，也可能重視家人在外的表現。
- 新認識朋友時，命主容易注意對方的形象、能力與做事水準。

**禁止跨越**

- 人物特質與命主自己的感受必須分開。
- 不把媽媽或手足的紫微直接算成命主自己的紫微個性。
- 不預設命主一定有手足。

### 3｜夫妻宮

**選用分面**

- `relationship.attitude`
- `relationship.needs_expectations`
- `relationship.preferred_partner`
- `relationship.interaction`

**推導**

```text
紫微需要尊重、體面與認可（F）
→ 夫妻宮的感情態度及相處（Registry）
→ 關係裡重視互相尊重，不希望被公開看輕
→ 容易欣賞有能力、形象整齊或做事有水準的人（D）
```

**可用表現**

- 感情可以不華麗，但對方公開不給面子或貶低自己，容易讓命主很受傷。
- 容易希望兩人互相成就，而不是一方長期否定另一方。

**禁止跨越**

- 不預設命主已婚、有伴侶或對象性別。
- 不預測結婚、分手、外遇及時間。
- 不放入性生活、工作在外或職場合作。

### 4｜子女宮

**選用分面**

- `care.children`
- `care.pets`
- `pleasure.eating`
- `pleasure.play`
- `pleasure.travel`
- `possessions.owned_items`

**推導一：照顧與所有物**

```text
紫微重視面子、品質及外在形象（F）
→ 子女宮的照顧對象及所有物（Registry）
→ 希望自己負責的人事物有品質、拿得出手
→ 對小孩可能有表現期待；對寵物可能挑外型或品種（D／T）
```

**推導二：吃、玩、旅遊**

```text
紫微不希望生活顯得寒酸或失禮（F）
→ 子女宮的實際享樂選擇（Registry）
→ 選餐廳、住宿或行程時重視質感與體面（D）
```

**可用表現**

- 對小孩可能希望有才藝、有成就或在外表現得體，但不能把期待變成小孩一定成功。
- 若有養寵物，面子與形象需求可能延伸成偏好看起來較高貴、能代表自己品味的品種貓；這是可能例子，不是每位命主都會養或購買品種貓。
- 旅遊住宿、餐廳及娛樂安排可能不喜歡太粗糙或太失禮。

**禁止跨越**

- 不談性生活、家門外或財庫。
- 不把「買品種貓」寫成固定事件。
- 不在此重複購買預算、花錢方式或存錢方式。

### 5｜財帛宮

**選用分面**

- `money.view`
- `money.earning`
- `money.spending`
- `money.management`
- `money.practical_use`

**推導**

```text
紫微重視規模、名聲、品質與資源整合（F）
→ 財帛宮的看錢、賺錢及用錢（Registry）
→ 希望金錢能帶來選擇權、體面及更大的發展空間
→ 可能重視品牌、管理、團隊或能放大成果的賺錢方式（D）
```

**可用表現**

- 看錢不只看夠不夠用，也容易在意錢能不能把生活、品牌或工作規模做得更完整。
- 花錢時可能願意為品牌、品質、形象及重要場合付出較多。
- 賺錢上可能偏好能累積名聲、整合資源或建立規模的方法。

**禁止跨越**

- 不斷言實際收入、財富或投資成敗。
- 不把領導傾向寫成一定靠管理職賺錢。
- 不談存錢與財庫；這些歸田宅宮。

### 6｜疾厄宮

**選用分面**

- `body.care_direction`
- `body.use_consumption`
- `body.inherited_tendency`
- `body.stress_response`

**推導**

```text
紫微重視形象，不喜歡顯得狼狽（F）
→ 疾厄宮的身體使用與保養（Registry）
→ 不舒服時仍可能先維持體面或撐住（D）

紫微講義對應脾胃與消化（L）
→ 疾厄宮的保養方向（Registry）
→ 提醒規律飲食、休息及留意消化狀況（D）
```

**可用表現**

- 不喜歡讓自己看起來狼狽，因此要留意是否為了維持形象而延後休息。
- 可提醒規律吃飯、休息並留意脾胃與消化狀況。

**禁止跨越**

- 不診斷疾病，不預測發病、手術或事故。
- 不用「富貴病」替客戶定性。
- 遺傳相關內容只作傾向提醒，不在父母宮重複展開。

### 7｜遷移宮

**選用分面**

- `outside.presentation`
- `outside.relationships`
- `outside.others_perception`
- `outside.inner_thought`

**推導**

```text
紫微重視形象、尊重與被看見（F）
→ 遷移宮的在外呈現及外界觀感（Registry）
→ 在外會顧及體面，別人可能感受到主見、份量或距離
→ 內心在意自己是否被尊重（D）
```

**可用表現**

- 在外通常不希望自己失禮，會注意說話、形象及場合。
- 外界可能感受到命主有主見或有距離感；這是別人的可能感受，不是完整人格定論。
- 被尊重時比較容易展現整合與帶領能力，被公開看輕時可能先防衛。

**禁止跨越**

- 不把出國、搬家、出差或交通事件寫入 D1。
- 不把外界觀感當客觀事實。
- 外在表現、外界觀感與內在想法不可合成同一欄。

### 8｜交友宮

**選用分面**

- `social.opposite_gender_siblings`
- `social.friends`
- `social.coworkers`
- `social.team_interaction`

**推導**

```text
紫微重視能力、形象、尊重，也需要團隊（F）
→ 交友宮的朋友、同事及團隊關係（Registry）
→ 容易欣賞做事有水準、能互相給面子的人
→ 團隊中希望意見被重視，也需避免只有排場而缺少合作（D）
```

**可用表現**

- 交朋友時可能重視對方的能力、形象與做事水準。
- 一般同事與團隊互動中，命主容易在意彼此是否尊重專業與分工。
- 紫微需要團隊，但不能因此推定一定有人幫忙；是否獲得幫助仍要看其他星曜與實際關係。

**禁止跨越**

- 不建立「異性別同輩」。
- 不把主管放入一般同事。
- 不建立固定的主管溝通分面。

### 9｜官祿宮

**選用分面**

- `work.attitude_values`
- `work.direction`
- `work.method`
- `work.role_environment`
- `work.focus`

**推導**

```text
紫微重視被看見、重要性、品質及資源整合（F）
→ 官祿宮的工作價值、方式與角色偏好（Registry）
→ 希望負責有份量的工作，成果可被看見
→ 可能偏好品牌、管理、整合資源或有發展空間的環境（D）
```

**可用表現**

- 工作上可能希望負責重要事情，而不是長期只做看不到意義的瑣事。
- 偏好成果有品質、能被認可，也可能想參與規畫或整合資源。
- 品牌公司、管理或帶團隊可以是例子，但不是唯一職業答案。

**禁止跨越**

- 不保證命主會當主管或適合所有管理工作。
- 不談一般同事、伴侶、升遷或失業事件。
- 不把「官祿主」直接轉成職業結果。

### 10｜田宅宮

**選用分面**

- `home.living_environment`
- `home.nearby_environment`
- `home.family_interaction`
- `home.family_background`
- `reserve.saving_method`
- `reserve.accumulation_retention`

**推導一：家與附近環境**

```text
紫微重視門面、品質及受人尊重（F）
＋ 講義明寫高樓、好地段、漂亮大樓及門面（L）
→ 田宅宮的居家與附近環境（Registry）
→ 希望住家整齊、有質感，客人來時拿得出手
```

**推導二：存錢與資產保留**

```text
紫微願意為體面、品質及可見成果投入（F）
→ 田宅宮的存錢與資產保留（Registry）
→ 可能較願意為有品質、能代表成就或長期保留的目標存錢（D）
```

**可用表現**

- 對住家門面、客廳、擺設、整齊度及整體質感可能有要求。
- 居住環境可條件式提到高樓、好地段、漂亮大樓或大家知道的地方。
- 家人之間可能因為都在意面子而有距離，事情不容易直接講開。
- 存錢可能需要一個讓自己覺得有價值、有品質或拿得出手的明確目標。

**禁止跨越**

- 不寫成命主一定住高樓、住好地段、有房或有錢。
- 不保證一定能存到錢或守住資產。
- 目前不談風水吉凶。

### 11｜福德宮

**選用分面**

- `inner.spiritual_enjoyment`
- `inner.social_values`
- `inner.blessing_luck`
- `inner.subconscious`
- `inner.taste`
- `inner.will_endurance`
- `inner.enjoyment_motivation`

**推導一：精神享受與品味**

```text
紫微重視體面、品質及被尊重（F）
→ 福德宮的內在滿足、品味及社會價值（Registry）
→ 內心希望生活不要太寒酸，喜歡有質感及被善待的感覺（D）
```

**推導二：意志與續航**

```text
紫微的皇帝角色習慣資源與團隊，不以長期粗重硬撐為自然選擇（F／T）
→ 福德宮的意志與內在續航（Registry）
→ 可能較不主動選擇高難度、長時間靠意志硬撐的活動（D）
```

**可用表現**

- 內心希望生活有品質，也容易把尊重、體面及成就感視為「過得好」的一部分。
- 吃、玩、旅遊帶來的精神滿足，可能來自舒適、質感、被好好對待及不用顯得狼狽。
- 意志力可以寫成相對較弱或不偏好長期硬撐，但不能簡化成懶惰、沒能力或一定不能吃苦。

**禁止跨越**

- 不把花錢、賺錢或來財方式放進本宮。
- 不斷言命主一定幸運、有福氣或老年生活如何。
- 不把「皇帝」比喻直接當客戶結論，必須翻成內在動機及選擇。

### 12｜父母宮

**選用分面**

- `authority.father_person`
- `authority.relationship_impact`
- `authority.elder_attitude`
- `authority.upbringing`
- `authority.hierarchy`
- `authority.institution`

**推導**

```text
紫微重視面子、尊重、形象及話語份量（F）
→ 父母宮的父親／長輩現象及命主權威關係（Registry）
→ 父親或重要長輩可能在意家人是否尊重其意見
→ 命主面對長輩、上位者及制度時也容易注意尊重與階層（D）
```

**可用表現**

- 爸爸或主要長輩可能很在意面子、家庭形象及自己的意見有沒有被重視。
- 命主可能覺得對方有距離、希望掌握重要決定；這是命主的可能感受，不等於客觀判決。
- 沒有爸爸或不適合談爸爸時，可以轉為重要長輩、教育方式及命主面對權威的態度。

**禁止跨越**

- 不預設父親存在、同住、關係好壞或實際能力。
- 單星紫微不能直接推出控制力強或很有能力；若有紫微化權等額外依據，再由相應規則補充。
- 不在父母宮詳談脾胃、消化及遺傳弱項；相關提醒集中疾厄宮。
- 抽象政府制度不是前星人物。

## 舊 A2 校正紀錄

| 舊 A2 內容 | 本案例處理 |
|---|---|
| 父母宮同時展開身體遺傳及身體使用 | 父親／長輩保留在父母宮；身體與遺傳集中疾厄宮。 |
| 福德宮談花錢及來財 | 保留精神享受、社會價值、潛意識、品味、意志與享樂動機；金錢移回財帛。 |
| 田宅宮談風水 | 保留居家、附近環境、家人及存錢；排除風水吉凶。 |
| 官祿宮談同事及感情 | 工作留官祿；同事回交友；感情回夫妻。 |
| 僕役宮使用泛稱平輩 | 改用交友宮的朋友、一般同事、團隊及異性別兄弟姊妹。 |
| 子女宮談性生活、家外與財庫 | 全部排除；存錢與財庫回田宅。 |
| 夫妻宮談工作在外 | 排除，夫妻宮專注感情。 |

## 對模型設計的結論

1. 模型不應直接取得整份舊 A2 後自由選句。
2. 程式先依 Registry 產生可用分面，再提供紫微固定核心及有權使用的特殊對應。
3. 模型必須輸出「核心引用 → 分面 → 推導機制 → 可能表現」，不能只交客戶文案。
4. 每項可能表現應保留 `F`、`L`、`T` 或 `D` 的來源類型。
5. `D` 類表現可以由模型產生，但必須通過：
   - 未跨宮。
   - 未改寫固定核心。
   - 未宣稱真實事件。
   - 未把可能性寫成事實。
   - 未加入來源沒有的星曜語意。
6. 客戶報告只挑代表性內容；內部驗證結果保留完整候選，不因報告濃縮而遺失。

## 下一個驗證層

紫微單星十二宮已足以驗證 Registry 與核心轉譯，但還不能驗證真正命盤推演。下一層應使用一個不含真實出生資料的雙宮案例，依序驗證：
