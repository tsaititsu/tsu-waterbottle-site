# 飛化推理公式研究

> 範圍：只比較本文末尾列出的四份 primary sources。
>
> 結論用途：提供 D1／F1 飛化推理與客戶輸出的共同公式；若舊規格與正式基準衝突，以正式基準版 v1.2 為準。

## 結論摘要

飛化不是把一顆星「飛進」另一宮，而是由出發宮 A 形成影響來源，使落入宮 B **原本存在**的指定星曜 S 產生祿、權、科或忌 H。第一層先解釋「A 憑什麼使 B 改變」，星曜只在最後修飾「這件事透過什麼方式發生」。若 A→B 本宮已能自洽，不得固定拉入對宮；若 B 本命已有生年四化，飛化只能解成觸發、加重、引動或帶出，不能說成 A 新創造了原有底色。

來源：S1 §0.6，L176–221；§7.2–7.6，L795–1017。S2 §三，L63–87。

## 一、可實作的飛化公式

設：

- `A`：出發宮
- `B`：落入宮
- `S`：被飛化星曜
- `H`：四化類型，`祿｜權｜科｜忌`
- `Opp(B)`：B 的對宮
- `Natal(B)`：B 的本命生年四化底色

則一條合法飛化的推理可以寫成：

```text
前置驗證：
  A、B 存在
  ∧ S 原本存在於 B
  ∧ (S, H) 是合法四化組合

核心推理：
  PalaceCause = A 的人／事／物／行為／資源／壓力
                為什麼能讓 B 的人生領域產生變化

  TransformedCause = Apply(H, PalaceCause → B)

  ExplainedCause =
    若 A本宮 → B本宮 已自洽：TransformedCause
    否則：TransformedCause + 必要且最小的 Opp(B) 補因

  NatalAdjusted =
    若 B 已有生年四化底色：
      將本條改寫為觸發／加重／引動／帶出該底色
    否則：
      保留本條新增的長期作用

  StarModified =
    用 S 的核心說明上述作用「以什麼方式」發生

  Candidate =
    StarModified
    → 可觀察的長期行為
    → 對象／生活領域
    → 可能現象
    → 不斷定事件已發生的白話例子
```

其中「程式可確定」與「模型推理」應分工：程式先驗證 A、B、S、H 與對宮映射；模型只處理宮位因果、星曜方式與生活行為橋接。非法飛化不得送入模型。

來源：S4 §一，L9–32；§三，L110–140。

## 二、固定推演順序

正式基準應採以下順序：

1. 讀 A 宮完整的人、事、物、環境與行為含義。
2. 讀 B 宮完整的人、事、物、環境與生活領域。
3. 暫不使用星曜，先建立 `A本宮 → B本宮` 的宮位因果。
4. 放入祿、權、科、忌的基本動作。
5. 檢查本宮因果是否自洽、命主能否理解。
6. 只有不自洽時，才用對宮補「為什麼成立」；對宮不能取代本宮。
7. 檢查 B 宮本命是否已有生年四化底色。
8. 最後加入被飛化星曜，說明作用方式。
9. 反推當代生活中的可觀察行為與可能現象。
10. 產生完整候選池、去重，並保留排除理由。
11. 經跨宮整合與規則審核後，才進客戶表達層。

可縮寫為：

```text
宮位因果
→ 化象動作
→ 本宮自洽檢查
→ 對宮補因（必要時）
→ 本命底色檢查
→ 星曜修飾
→ 行為橋接與候選池
→ 審核
→ 客戶輸出
```

正式基準的逐條飛化骨架還要求保留 A 宮來源引用、B 宮來源清單、生活行為、B 宮現象、白話收束，以及「行為 → 對象 → 現象」檢查；同一來源宮可共用來源總表，但每條飛化仍須獨立反推。

來源：S1 §0.6，L187–215；§7.7，L1021–1052。S3 §二，L31–112。S4 §二，L80–106；§六，L238–288。

## 三、四化的基本動作

| 四化 | A 對 B 的基本動作 | 推理時要問 |
|---|---|---|
| 化祿 | A 用自身特質、人物、資源、吸引力或行為，使 B 增加緣分、機會、好感、資源或好處。 | A 提供了什麼，使 B 更容易靠近、增加、被需要或受益？ |
| 化權 | A 用自身特質、壓力、責任、主導力或事件，使 B 增加責任、掌握、決定權、主導權或壓力。 | A 為何使 B 成為需要處理、掌握、負責或決定的領域？ |
| 化科 | A 用整理、說明、修飾、包裝、身分、條件或外顯需求，使 B 被看見、整理、說明、修飾、緩和，或形成名聲。 | 是命主主動整理／表現而被看見，還是 A 的既有條件使 B 自然受到注意？ |
| 化忌 | A 的特質、缺口、壓力、不滿、依附、期待或未滿足，使 B 卡住、不開心、放不下、形成空缺，或觸發 B 原有問題。 | 哪個期待未滿足、責任未說清楚或缺口被碰到？命主之後如何持續在意、追求或補足？ |

化權不能窄化成「命令別人」；它也可能是選人、選環境、掌握資源、預先定規則或承擔責任。化科包含主動彰顯與條件彰顯。化忌不能直接等同失敗，而要找出空缺、在意與補足機制。

來源：S1 §7.3，L855–905。S2 §六，L200–240。S3 §三，L116–177。

## 四、星曜的角色與合法性

星曜的角色不是第一層原因，也不是被新增到 B 宮：

```text
宮位：決定哪一類人事物、為什麼 A 能影響 B
四化：決定 B 增加、變重、被看見或形成空缺的動作
星曜：最後說明命主怎麼做、怎麼想、怎麼反應，以及作用如何發生
```

實作硬規則：

- `S` 必須原本存在於 B；不存在就屬非法資料，不得由模型補星。
- 若 B 是合法雙星組合，只讓指定的 `S` 化祿／權／科／忌，另一顆主星保持原狀。
- 同一顆星可以同時承受生年四化與不同宮位飛來的四化；全部保留，不互相取消，也不先武斷比較強弱。
- 同一落入宮收到多條不同來源的飛化時，各條影響同時存在並保持獨立；正向與負向不互相抵銷、不加總成單一吉凶，也不選一條取代其他條。
- P1 的兩宮完整星曜分析可以作為 F1 背景，但 F1 成文時仍須先立宮位因果，最後才用星曜修飾。

來源：S1 §0.6，L178–208；§7.6，L988–1017。S2 §三，L63–87。S3 §二 Step 4，L79–93。S4 §三，L116–140；§六，L248–272。

## 五、對宮規則

正式基準的預設路徑只有：

```text
A本宮 → B本宮
```

對宮是條件式補因，不是固定連動：

- 若本宮已能自然、清楚地說明 A 為何使 B 改變，禁止硬加對宮。
- 只有本宮因果不合理、跳躍，或命主聽不懂時，才啟用對宮。
- 對宮只補足「為什麼這件事成立」，不能取代 A→B 的本宮主幹。
- 每次啟用須留下：本宮不足點、使用哪個對宮、補了什麼原因、補後是否合理。

舊 D1 模組保留四層探索順位：

```text
1. A本宮 → B本宮
2. A本宮 → B對宮
3. A對宮 → B本宮
4. A對宮 → B對宮
```

這四層可當候選探索的 fallback，但不得理解為四層都必跑。依 v1.2 最高規則，第二至第四層都必須受「直接解釋不足才展開」約束；正式客戶結論優先只保留能補足因果且有明確理由的最小對宮資訊。

來源：S1 §7.4，L909–957。S2 §五，L144–166。

## 六、本命底色

若 B 宮本命已有生年四化，該底色先於本條飛化存在。F1 必須明列：

```text
B 是否已有生年四化
→ 哪顆星化什麼
→ 命主原本在 B 有何長期底色
→ 本條 A→B 只是如何觸發／加重／引動／帶出
```

禁止把 B 原有的生年四化說成由 A 新造成。若同一顆星還承受其他來源宮的飛化，各作用都保留，不互相取消；在資料不足時也不先宣稱某一作用較強。

來源：S1 §0.6，L201–208；§7.5，L961–984。S2 §三，L82–87。

## 七、候選池與客戶輸出

### F1 推理層

每條合法飛化各自呼叫一次，且先等待 A、B 兩宮的 P1 結果。F1 應：

- 對 A 的每個主要含義與 B 的每個主要含義嘗試建立連接。
- 回報 `A含義 × B含義` 覆蓋矩陣，標記已建候選、合併同義或排除。
- 只保留命理成立、現實合理、彼此不同的候選；不同措辭但同一行為機制不算新候選。
- 每條候選包含一個長期「行為模式」與一個或多個可追溯的當代生活例子；所有彼此不同且通過驗證的機制與例子都保存在內部候選池。
- 使用「可能、容易、例如」等措辭，不斷言事件已發生。
- 人物宮位先描述其如何影響命主；不得反推對方已失業、破財、生病等具體事件。
- 年份、疾病、法律、投資成敗等具體事件留給 D2。

來源：S2 §一–二，L1–14；§七–八，L300–368。S3 §一–二，L9–112；§四，L181–195。S4 §六，L238–288。

### O1 客戶表達層

推理與表達必須分開。O1 只能使用審核通過的 S1，以及產品需要的 P1／F1 證據；它可以選擇、排序、縮短與改寫，但：

- 客戶文章依落入宮的生活主題排列，不建立飛化或其他內部引擎的教學章節。
- 不得新增推理層沒有的命理結論。
- 不得把候選可能改成必然事件。
- 所有不同核心結論與作用機制都必須保留。
- 同一落入宮的多條飛化可按生活主題相鄰排列，但每條都要保留自己的出發來源、四化與星曜作用，不得混成一條無來源的綜合句。
- 多條影響鏈形成相同可觀察行為時，內部來源不合併；客戶文章可以只寫一次該行為，但必須同時列明所有形成來源。
- 同一出發宮有多個命盤支持、但尚未由客人背景確認的角色或經驗時，客戶版使用包容性的來源描述；不武斷選定唯一角色，也不把相同機制逐一重複。
- 飛化若與本對宮或三方暗合等其他引擎形成相同可觀察行為，內部仍保留各引擎證據；客戶版只寫一次並可說明有多個命盤因素加強。不同機制或矛盾面向不得因此合併。
- 同一作用機制只選一至兩個最容易理解、最符合主要生活地區的代表例子；可以省略同義或重複例子，不可刪除不同結論。
- 未刊登的合法例子仍留在內部候選池，供大限、流年與後續聊天室使用。
- 不得為流暢而刪除重要矛盾。

客戶版每條飛化的最小白話結構建議為：

```text
因為 A 的＿＿（來源／條件／行為），
使 B 在＿＿（領域）增加／變重／被看見／形成空缺；
若需對宮，以一句話補足成立原因；
若 B 有本命底色，說明本條只是觸發或加重；
這件事會透過 S 的＿＿方式表現，
所以命主長期可能＿＿。
例如＿＿（不斷定已發生的生活情境）。
```

老師最新修正指出，這個骨架仍不能直接拿宮位分類詞交付客戶。正式文字必須再轉成：

```text
來源人物、教育或生活經驗
→ 命主形成的內在感受、價值或缺口
→ 命主反覆出現的選擇與行為
→ 可能形成的生活狀態或困擾
```

例如父母宮飛天機忌至財帛宮，不能只寫「父親影響命主的理財規劃」。較完整的生活因果是：父親或長輩的教育模式與金錢經驗，使命主逐漸覺得錢總是不夠，因而想多賺錢、研究許多方向並持續尋找賺錢方法；天機化忌使這種尋找容易反覆，仍不容易找到真正好的方法或可能選錯方向。

「理財規劃」「金錢價值」可以保留為內部受影響分面，不能拿來取代客戶可感受到的心理、行為與生活結果。

老師進一步確認，公式與客戶文章之間還需要兩層轉換：

1. **語意生活化**：依因果主張推演命主可能形成的感受、價值、選擇與反覆行為。
2. **社會脈絡轉譯**：依主要生活地區，從同一條已核准因果中選擇自然語彙與表達方式。

兩層轉換都必須保持可追溯：人物、感受、行為與結果必須由出發宮含義、落入宮分面、四化動作及被飛化星曜核心共同支持。模型可以推演固定卡片沒有逐字列出的副業、轉職、投資、消費等現代例子，但必須顯示它們如何由當次星曜與宮位機制推導出來。社會脈絡不能改變公式、替客人捏造經歷，或讓不同星曜共用同一套生活文字。

例如同為父母宮飛忌至財帛宮：

- 天機化忌可延伸為想多賺錢、研究許多方法與方向，卻反覆尋找仍難以找到好方法。
- 太陰化忌應依太陰核心延伸到居家環境、布置、吃喝或生活細節的花費與滿足，可能花了仍覺得不夠。

兩條飛化共享來源宮、落入宮及化忌的不足機制，但被飛化星曜不同，心理感受與生活行為就不能寫成同一套答案。

來源：S1 §7.7，L1021–1052。S4 §一，L52–76；§十一，L419–441。

## 八、版本衝突與處理

| 議題 | 較早／工作版寫法 | 正式基準 v1.2 | 採用方式 |
|---|---|---|---|
| 第一層原因 | S2 先完成兩宮整宮分析，內含主星、四化、輔煞與對宮；S3 的 Step 1、2 也先收整宮資料，Step 4 再帶兩端星曜。 | 明定「先不看星曜」，先解 A 為何能使 B 改變；星曜最後才說明方式。 | 資料準備仍保留完整 P1，但 F1 的推理／成文順序以 v1.2 為準。 |

| 本命底色 | S2 說同星可同時承受生年與多來源飛化，全部保留。 | 新增明確檢查：不得把 B 原有底色說成 A 新造成。 | 兩者相容；在 F1 增加必填的 `natalBaselineCheck`。 |

依 S4 已明定的知識來源順位，並結合各文件自述狀態，建議：

1. **老師在對話中的最新確認**：若未被收錄到本次四份來源，仍須先回填為可追蹤規則，不能靠模型口述猜測。
2. **S1 正式基準版 v1.2 的新增最高規則**：本次關於推演順序、對宮補因、本命底色、星曜延後的最高權威。
3. **已確認核心規則／老師確認案例**：S2 的核心模組規則與 S3 明標「老師已確認」的案例，可補足候選機制與星曜細節；與 S1 衝突時降級。
4. **S4 編排規格**：權威於流程邊界、程式／模型分工、F1 依賴、結構化輸出、審核與 O1；命理順序若落後於 S1，應更新實作而非反過來覆蓋 S1。
5. **S3 工作推導**：可產生候選與例子，但必須保留狀態，不能冒充老師確認。
