# 空宮借星必須在模型推演前由程式判定

每個目標宮位進入本對宮推演前，程式先建立不可變的空宮判定結果。空宮若有擎羊、陀羅、火星、鈴星、文昌或文曲任一顆，就不能借對宮主星；其他空宮只借對宮十四主星及實際附著其上的生年四化。祿存不阻止借星，且留在本宮作在地助力。

通過資格時，借入主星正式成為目標宮的核心，代表表裡如一，不是較弱、隱藏或次要人格；同一借入星不能再重複算成對宮表達通道。不能借星時，模型只能依宮位分面及本宮原有星曜建立主張，不能把對宮主星提升成本宮核心。

這個決策把借星資格、借入範圍及生年四化綁定留在 deterministic input layer。模型只負責依已核准核心做語意推演，不能猜測、放寬或取消借星規則。
