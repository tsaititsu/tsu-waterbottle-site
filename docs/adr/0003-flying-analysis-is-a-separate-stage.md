# 飛化使用獨立分析階段

飛化需要整合多宮關係，因此不混入第一次單宮星曜分析。獨立階段產生一份經驗證的權威飛化結論，客戶文章只接收自然語言結果，避免基本人格被複雜飛化資訊淹沒。

飛化不是把一顆星從出發宮搬到落入宮。正確的命盤事實是：

> 出發宮的宮干，使落入宮原本存在的指定星曜產生祿、權、科或忌。

每一項飛化必須保存為一條有方向、分層驗證的影響鏈：

`出發宮人物／事情 → 落入宮受影響面向 → 四化基本動作 → 被飛化星曜的發生方式 → 可觀察的生活連接`

推演順序固定為：

1. 先確認出發宮代表哪些人物、關係、動機、資源、壓力或生活領域。
2. 再確認落入宮哪一項價值、決定、規劃或生活狀況受到影響。
3. 不先看星曜，先判斷出發宮為什麼能使落入宮產生變化。
4. 套用祿、權、科、忌的固定動作。
5. 優先用出發宮與落入宮本身建立因果；只有直接原因不成立時，才使用對宮補因。
6. 若落入宮原本已有相同生年四化底色，飛化只能描述為觸發、加重、引動或帶出，不能說成出發宮新造成。
7. 最後確認落入宮原本存在的被飛化星曜，使用該星曜核心說明這件事透過什麼方式發生。
8. 建立可觀察但不斷定已發生的生活連接；模型可以推演來源未逐字列舉的現代例子，但其中的人物、感受、行為與結果都必須同時受出發宮、落入宮、四化及被飛化星曜支持。

飛化只新增跨宮因果，不改寫出發宮或落入宮原有的星曜結論。內部只保存一份權威影響鏈，避免兩個宮位各自生成互相矛盾的答案。

同一落入宮若收到多條飛化，每條影響鏈都同時成立並分開保存。偏幫助與偏困擾的作用不互相抵銷，不加總成單一吉凶，也不選一條覆蓋其他條。客戶報告可以把它們排列在同一生活主題下，但必須逐條說明不同來源與表現方式。

若不同飛化最後形成相同的可觀察行為，內部來源與機制仍各自保留；客戶文章只寫一次該行為，並在同一段中列明所有支持它的來源。這是文字去重，不是推理合併。

同一出發宮可能同時代表多個合法來源，但本命報告未必知道客人的真實人生背景。例如父母宮可涵蓋爸爸、重要長輩、教育方式與成長中的家庭經驗。此時客戶文章使用包容性的來源描述，不硬選唯一來源，也不把相同機制按每個可能角色重複成文；只有未來取得客人背景後才能進一步確認。

客戶報告以落入宮位作主要呈現位置，因為該宮代表實際受到影響的生活面向；句子必須明確交代出發來源。出發宮位如需提醒，只放一則簡短的跨宮提示，不重複整段分析。

飛化在內部保持獨立引擎，在客戶文章中卻不建立獨立的「飛化分析」章節。它應放入落入宮對應的生活主題，例如財帛宮的看待金錢、賺錢、花錢、理財或實際用錢；存錢與財庫則回到田宅宮。技術來源繼續由內容格與證據鏈保存。

內部候選池保存所有彼此不同且通過驗證的飛化結論、作用機制與生活例子。客戶報告仍須保留每一種不同的核心結論與作用機制，但同一機制只選一至兩個最容易理解的代表例子；可以省略重複例子，不能用縮短篇幅為理由刪除不同結論。未刊登的合法例子繼續保留，供後續大限、流年與聊天室使用。

例如父母宮飛天機忌至財帛宮，先確定父親、長輩、教育模式或過去金錢經驗是影響來源，再確認它如何讓命主形成「錢總是不夠」的感受。化忌形成持續在意與補足，財帛宮內原有的天機則使命主想多賺錢、研究很多方向、持續尋找賺錢方法，卻仍不容易找到真正好的方法。客戶版要寫出這條生活因果，不能只用「理財規劃受到影響」等抽象分類詞代替。

若同一條父母宮至財帛宮改為太陰化忌，不能沿用天機的研究方法與方向選擇。太陰核心會把空缺帶到居家環境、布置、吃喝或生活細節的花費與滿足感，命主可能在這些地方持續覺得還不夠。星曜不同，合法的生活延伸也必須不同。

父母宮飛化至命宮亦同：父親或長輩是來源，人生價值、人生規劃與整體自我狀態是受影響面向，命宮內被飛化的星曜說明具體作用方式。
