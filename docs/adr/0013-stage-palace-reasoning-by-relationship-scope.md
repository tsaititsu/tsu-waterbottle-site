# 宮位推演依關係範圍分成多個引擎

單宮資料只是分析輸入，不是完整宮位結論。若只看本宮就產生最終解讀，會漏掉對宮、三方四正與暗合共同形成的結構。

每個目標宮位依序使用：

1. **本宮主軸＋對宮表現推演引擎**：一般有主星時，本宮主星決定能力、個性與價值核心，對宮主星決定這個核心主要透過什麼方式展現；空宮則先依 ADR 0016 由程式固定借星資格與核心模式。生年四化跟著星曜一起處理。
2. **三方四正＋暗合影響推演引擎**：接收已驗證的本對宮結果，另外建立其餘三方宮位與暗合如何影響本宮決定及狀況的來源鏈。
3. **獨立飛化推演引擎**：飛化另行分析，不塞入前兩個結構引擎。
4. **宮位整合**：只整合各引擎已驗證的結論，不以摘要取代任何原始主張。

第一個引擎不是把兩宮完整文章相加。一般模式下本宮是主軸、對宮是表現通道；符合資格的空宮以借入主星為本宮核心並視為表裡如一，不能借星的空宮則不得把對宮提升成本宮核心。分析相反方向時，必須重新判定該目標宮的核心模式。

對宮預設只抽取能讓本宮核心落到現實的表現方式，不把對宮星曜的所有特質搬入本宮。只有固定對拱規則、生年四化或煞忌提供明確依據時，才能另外加入對宮形成的壓力、矛盾或其他修飾。

第二個引擎不得把對宮當成新資料重新推演一次；對宮已在第一個引擎完成，第二個引擎只引用其核准結果並加入其餘結構。

三方四正與暗合都不能改寫或取消本宮結論：

- 三方四正的影響較明確，說明其他宮位的祿、權、科、化忌或煞星如何支持、施壓或干擾本宮。
- 暗合使用同樣的正負影響來源，但屬於較不容易直接察覺、潛移默化的影響。
- 祿、權、科偏向增加助力、能力或正向條件；化忌與煞星偏向帶來不順、壓力或負向干擾。
- 同時存在的正負影響分開保留，不合併成單一分數，也不拿其中一項抵銷另一項。

客戶文章在每個生活主題中，先呈現本宮直接主星、已核准借入主星或不可借空宮的在地星曜所形成的原始想法、價值與行為，再說明輔星、祿權科、煞忌、三方暗合或飛化如何幫助、加強、施壓或干擾。煞忌即使讓命主感受深刻，也不能取代原本的核心結論。

生年四化不另設推演引擎。它跟隨被四化的星曜，在本宮＋對宮基礎推演中一起解讀，並保持星曜、Actor 與四化作用的綁定。飛化才使用獨立引擎。
