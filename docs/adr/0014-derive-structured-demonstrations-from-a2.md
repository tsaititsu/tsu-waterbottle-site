# A2 原文與結構化推演示範分層

168 筆 A2 單星十二宮原文完整保留，不直接整包作為模型答案庫；另由來源衍生統一格式的推演示範卡，明確拆開主星核心、宮位分面、機制連接、可能表現、結果邊界、規則身分與來源。模型每次只取得當次星宮所需的核心卡、分面卡、相關示範與特殊規則，學習「怎麼推演」而不是照抄答案。

同一個 A2 段落若混有講義固定落點、整理推論、老師確認案例或禁止斷言，必須拆成各自保存來源與可信層級的原子主張，不能整段共用一個權威等級。具體欄位、批次轉換與人工驗證流程延後到素材工程階段決定。

這個決定接受額外的素材整理與驗證成本，換取較低的 Token 用量、可追溯來源、星曜專屬性與穩定的生活推演。A2 是金標、校準與禁區，不是唯一合法句子；模型仍可產生未逐字列出的例子，但必須回推到固定核心與分面。
